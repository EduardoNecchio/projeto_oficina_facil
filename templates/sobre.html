SOBRE O PROJETO

Oficina Fácil

O Oficina Fácil é um sistema web acadêmico desenvolvido para apoiar a rotina de uma oficina mecânica.

A aplicação permite organizar clientes, veículos, catálogo de serviços e ordens de serviço, mantendo os dados persistidos em um banco relacional SQLite.

Tecnologias

Python · Flask · SQLite · SQL nativo · HTML · CSS · Jinja2

Organização

As rotas estão no arquivo app.py, as consultas no db_sql.py e a estrutura do banco no schema.sql.
